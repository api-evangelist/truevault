# TrueVault

> TrueVault provides developer infrastructure for storing and managing sensitive personal data in a compliant way. TrueVault Safe is a HIPAA-oriented REST API and secure datastore (Vaults, Documents, BLOBs, Users, Schemas, Search, Messaging, Scoped Access Tokens) authenticated with API keys or user access tokens via HTTP Basic. TrueVault's Polaris product is privacy-compliance software for ecommerce (US state privacy laws, GDPR, CCPA). Y Combinator-backed.

## APIs

- [TrueVault Safe REST API](https://docs.truevault.com/): REST datastore for sensitive data. Base URL https://api.truevault.com/v1. Resources: Users, Groups (Access Grid), Vaults, BLOBs, Documents, Schemas, Search, Messaging (Email/SMS), Password Reset Flows, Scoped Access Tokens.
